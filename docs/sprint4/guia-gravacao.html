Resposta curta: o que eu mostro?

Para cada melhoria, mostre duas coisas, nesta ordem:

ANTES = PRINT  Mostre a imagem de como era. A versão antiga não roda mais, por isso usamos print. Clique na miniatura e ela abre em tela cheia. Fale por 5 a 10 segundos e aperte Esc.

DEPOIS = AO VIVO  Mostre o sistema rodando de verdade (Telegram, painel e app), seguindo os passos.

A única exceção é a Melhoria 4 (segurança): antes e depois são prints, porque são respostas da API e não há tela para clicar.

O arquivo docs/ROTEIRO-APRESENTACAO.md é outra coisa: é para a apresentação ao vivo para a banca (10 min, sem prints de antes). Para o vídeo, ignore esse arquivo e use só esta página.

Antes de gravar

  1. Ollama aberto, npm run dev rodando e npm run demo:check com tudo ✅.
  2. Chrome com duas abas: painel localhost:5173 (logado como joao.atendente@claro.com.br, com o código do autenticador do celular) e app do cliente localhost:5174 (logado como carlos.cliente@email.com). A senha de todos é Claro@2024.
  3. Telegram (desktop ou web) aberto na conversa com @claro_omnichannel_mathcerq_bot.
  4. Esta página aberta em outra janela, para ver os passos e abrir os prints.
  5. OBS Studio gravando a tela inteira, com a webcam no canto (câmera aberta é regra da entrega), em 1080p.
  6. Zoom do navegador em 110–125% (Ctrl + +) para o texto ficar legível no vídeo. Notificações do Windows desligadas.
Dica: grave uma cena por vez e junte tudo na edição. Se errar, refaz só aquela cena. A IA leva de 15 a 50 s para responder: corte ou acelere essa espera na edição.

Depois de gravar

  1. Publique no YouTube como Não listado (ou Público). Abra o link numa aba anônima para confirmar que funciona sem login.
  2. Feche o documento no Word, se estiver aberto, e rode na raiz do projeto (PowerShell), trocando o link e os nomes: 
    $env:VIDEO_URL="https://youtu.be/SEU-LINK"; $env:EQUIPE="Seu Nome Completo — RM 00000"; npm run docs:sprint4
    Se a equipe tiver mais pessoas, separe com ; dentro de EQUIPE.
  3. Envie no portal o arquivo docs/sprint4/Entrega-Sprint4-Claro-Omnichannel.zip (Word + PDF com o link do vídeo na capa).
